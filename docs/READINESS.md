# Readiness — separate dimensions, not a single green flag

| Dimension | Initial conversion state | Required evidence |
|---|---|---|
| Existing functionality | source-observed internal-alpha baseline; historical tests/CI | current exact-head product/negative-path qualification |
| Input package | see PACKAGE-CHECKS snapshot | actual inventory/hash/source/extraction checks |
| Helper materialization | NOT RUN until bootstrap executes | BA-01…BA-52 and semantic review/receipt |
| Operational client/runtime | UNCONFIGURED until qualified | actual Codex help/profile/homes, bounded POSIX runtime, paths/roles |
| Remote publication | BLOCKED until explicitly configured/authorized | private repo identity, current CI, exact PR/report adapter, permissions |
| Conditional strategic merge | DISABLED until attributable scoped activation | accepted conversion, authority origin, required checks/side effects |
| Independent conversion closure | UNPROVEN | fresh isolated audit of full architecture/converted governance at exact accepted revision |
| Product pilot qualification | UNPROVEN for a new target | selected scope, real local entry point and recovery evidence, ICA matrix |
| Real deployment / release | NOT AUTHORIZED | human target/risk/data/host/identity/ops choice, applicable DHA and separate authorization |

Bootstrap structural success is not activation. A historical alpha report is not the new independent
closure audit. A ready command or complete work-order queue is not a release certificate. No
production deployment occurred merely because a loopback rehearsal passed. Track functional work,
uncertainty reduction and technical-debt reduction separately. Preserve deliberate exclusions.

M-CONVERSION: adopted code/history-safe governance, tests, client/role qualification, operational
canary if authorized, independent exact-revision audit and human acceptance. M-LOCAL-PILOT-EVIDENCE:
selected actual human/API/staff/DB/recovery paths, bounded fixes, fresh full matrix and human judgment.
M-EXTERNAL-PILOT/M-RELEASE remain D2, requiring real operator/host/network/identity/backup/monitoring
posture and explicit authority; no automatic promotion from internal-alpha.
