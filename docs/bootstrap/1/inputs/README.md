# SLAIF Asset Reservation — Concentrated OAP bootstrap inputs

**Existing-project workflow migration; not a new application; not an installed agent system.**

This package is for a separate, capable tool-using **Codex bootstrap agent**. It carries the
product agreement, a new canonical full architecture, the preserved accepted legacy architecture,
full and compact role documents, exact helper contracts, acceptance tests to implement, and
specific inactive work drafts. It does not contain a replacement application or production data.

## Use

Extract the ZIP into a fresh temporary directory **outside** the coding repository and strategic
workspace. The ZIP has no enclosing directory. Do not dump these input files at repository root:
the archive-root AGENTS.md is intentionally bootstrap-only.

Set OAP_REPO_ROOT to the existing checkout when appropriate; otherwise the proposed checkout is
`$HOME/codex-work/slaif-asset-reservation`. The proposed strategic workspace is
`$HOME/codex-supervision/slaif-asset-reservation`, overridable with OAP_STRATEGIC_HOME. Neither
path names an observed machine location. All three roots must be distinct and non-nested.

Start a capable Codex agent in the extracted directory and give it:

```text
Read AGENTS.md and execute INSTRUCTIONS.md. Use the bundled PLAN.md,
ARCHITECTURE.md, CRITICAL.md, specifications, blueprints, and source documents.
This is a conversion of the existing slaif-asset-reservation repository, not
new-project initialization. Materialize and validate the separate coding and
strategic workspaces. Do not execute product orders or start operational agents.
Stop before activation and write BOOTSTRAP-RECEIPT.md.
```

The bootstrap agent implements the specified local harness, generates the full workspace inventory,
expands every draft seed, runs disposable tests, archives old governing sources, and leaves the
conversion uncommitted and inactive. It must not copy the bootstrap constitution into the repo.
