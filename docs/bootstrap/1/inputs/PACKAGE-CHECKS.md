supersedes the old human-per-merge discipline only after human-reviewed adoption and attributable
activation. Bootstrap cannot use the new rule to publish or approve itself. Human product/D2/DHA/
milestone/release authority remains intact. Both operational clients are Codex; current model IDs
remain unconfigured and no alternate-client fallback is installed.

The source architecture is preserved byte-for-byte while a newly synthesized canonical root
architecture qualifies outdated/deferred claims. Source conflicts are enumerated in SOURCE-MAP,
not silently repaired as product code. Root PLAN is synthesized, not claimed to be a finalized
source supplied earlier. CRITICAL initialization is conditional on no existing local register.
Old Work Orders0001–0013 remain history; proposed continuation drafts cannot activate themselves.

All four roles, five-condition DHA admission, exact declarations/payload/disposition values, two
merge/target gates, report-only SELF publication, exact two-byte FIFO contract, quiescent migration,
safe recovery, dense-context coverage and independent exact-revision ICA obligations were checked
for consistency. Mechanical validators cannot establish human authority, semantic equivalence,
correct D1 admission, real client behavior or independent audit identity.
