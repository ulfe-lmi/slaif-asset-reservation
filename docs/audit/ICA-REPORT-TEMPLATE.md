# Independent Closure Audit — report template

This template contains no findings or audit approval. All fields below require actual evidence.

## Identity and scope
Actual auditor/context provenance, independence limitations, human scope reference, exact merged
repository revision, full architecture/plan identities, excluded systems/data and evaluated runtime.

## Requirement assessment
Use the architecture-derived matrix; one row per applicable SAR ID. Classifications are exactly
IMPLEMENTED / PARTIAL / ABSENT / UNPROVEN. Record enforcing path, real-boundary test/evidence,
negative cases, revision, limitations and reason. Approved deferrals are not missing rows.

## Findings and contrary evidence
Stable finding IDs, impact/severity, concrete reproduction or source observation, requirements,
smallest discriminating test, proof limitations and remediation recommendation. Ordinary defects
are not automatically CRITICAL entries. No fabricated confidence, dates, independent identity or
results. State failed/skipped/not-run/blocked checks separately.

## Judgment and boundary register
Applicable CRIT IDs and gates, human dispositions with provenance, unresolved D2 prerequisites,
combined risk and residual uncertainty. Audit does not adjudicate human decisions.

## Closure recommendation
Assess only the selected milestone at the evaluated revision. New work requires H/A/E/I/C-linked
orders and re-audit. Deployment/exposure/release and final human acceptance are not granted here.
