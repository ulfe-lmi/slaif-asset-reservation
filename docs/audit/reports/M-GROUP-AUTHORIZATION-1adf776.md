### ICA-GA-001 — Required: current-human guard missing on four older staff routes

**Authority:** human scope sections2/3/6/11; ARCHITECTURE A-16 “All application access requires current active non-service-account human eligibility”; retained staff-only asset discovery/private documentation contracts. The session was established through real `/login/` with CSRF, not `force_login` or mocked auth. The operator flag change is synthetic owned test data. **Smallest repair recommendation (H/A/E/I/C-linked):** preserve these existing interfaces and add a common current active authenticated non-service human **and** staff predicate to asset list/detail and the private-documentation branch. Preserve existing bearer-only operations and bearer refusal for inventory; preserve disabled-by-default production docs and the intentional explicit local public-doc configuration. Add focused real-session flag-transition negatives across these four routes with positive active-staff and negative anonymous/nonstaff/inactive/service/Bearer controls; keep Admin/member/management controls. No change is needed below this admission boundary, to booking services, policy/DB locking or identifier semantics. This ordinary defect does not satisfy DHA admission and needs no CRITICAL waiver.
