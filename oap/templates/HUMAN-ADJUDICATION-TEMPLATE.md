# Human adjudication template — separate human recording path

Only ACCEPTED, REJECTED, CHANGE REQUIRED and DEFERRED are allowed. Latest attributable ACCEPTED
alone clears the entry's scoped gate, with conditions verified; other/unverified dispositions block.
An agent signature/name or same bot-created comment cannot establish human authority. Source must be
retrieved/verified against a separately accepted human identity/signing policy. No identities are
preapproved by this template. Deployment/release permission remains separate.

```markdown
## HUMAN ADJUDICATION — CRIT-0001 — YYYY-MM-DD
- Decision: ACCEPTED
- Authority: <named accountable human>
- Conditions or required follow-up:
- Evidence/reference:
```

Record source provenance (permalink or signature plus digest), target scope/revision and verification
result outside the immutable original entry. If material corrective work is still required, use
CHANGE REQUIRED or DEFERRED, not a misleading unconditional ACCEPTED. The coding append helper
must reject this record type. Bootstrap creates no actual adjudication or populated authority grant.
